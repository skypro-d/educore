# User Manual

## Admin

1. Login at `/admin/login`.
2. Update branding, fees, and contact information in Settings.
3. Review applications from Applications.
4. Move applicants through review, exam, interview, approval, rejection, and enrollment.
5. Manage entrance exam subjects and questions from Entrance Exams.
6. Schedule interviews from Interviews.
7. Monitor Paystack payments from Payments.
8. Print reports from Reports.

## Parent / Applicant

1. Apply from `/apply`.
2. Save the generated applicant ID.
3. Pay admission fees from the tracking page.
4. Track status from `/track`.
5. Open `/student` to view the parent dashboard and download documents.
